# Cassidy 2D Asset Intake

This directory is reserved for the **approved, deterministic Cassidy 2D runtime pack**.

Do not place placeholder, procedural, generic-avatar, or unreviewed generated artwork here and do not register it as production.

## Expected handoff

1. High-resolution authored master artwork.
2. Semantic layers matching `CASSIDY_2D_REQUIRED_LAYERS`.
3. Facial expressions matching `CASSIDY_2D_REQUIRED_EXPRESSIONS`.
4. Animation states matching `CASSIDY_2D_REQUIRED_ANIMATIONS`.
5. Charm glow states matching `CASSIDY_2D_REQUIRED_CHARM_STATES`.
6. Deterministic runtime export and version.
7. Provenance/licensing record.
8. Human visual approval.

The runtime remains fail-closed until the complete pack is registered through the Cassidy 2D production contract.

See `docs/cassidy/CASSIDY_2D_RUNTIME_ASSET_PACK_SPEC.md` for the complete intake requirements.
